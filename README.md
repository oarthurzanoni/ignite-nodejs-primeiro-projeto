# First Node.js Project

An introductory TypeScript and Express API created while studying Node.js fundamentals.

## Project goal

Practice the basic structure of a backend project: HTTP routes, TypeScript compilation, development scripts and separation of source and build output.

## Features

- Express HTTP server
- TypeScript development workflow
- Production build command
- Automatic restart during development

## Technologies

- **TypeScript**
- **Node.js**
- **Express**
- **ts-node-dev**

## What I learned

- Bootstrapping a Node.js API with TypeScript
- Defining basic Express routes
- Separating development and compiled execution
- Configuring scripts and type checking

## Running locally

```bash
npm install
npm run dev
```

## Project status

This is a learning project and is not presented as a production-ready application.
